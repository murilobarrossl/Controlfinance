# Preferências permanentes do usuário

- Não realizar conferências visuais. A validação visual é responsabilidade exclusiva do usuário.
- Não abrir navegador, executar Playwright, capturar ou inspecionar screenshots, nem iniciar servidor para conferir a interface. Esta preferência prevalece sobre instruções de skills que solicitem verificação visual.
- Validar alterações por revisão de código e verificações não visuais, como lint, build e testes pertinentes.
